# 5 分钟上手

## 体验界面

打开在线演示，选择第二镜，调整景别或运动，观察提示词末尾参数。尝试把它移到第一镜之前，再读切镜逻辑，判断新的顺序是否仍然成立。复制提示词或导出 JSON 保存成果。

“载入示例主镜”会恢复固定的 4 镜；“重置此镜”会丢弃当前镜头的修改。画幅与风格写入提示词参数，不会重新生成插图。质量状态是“待人工检查”。

## 用自己的故事

1. 阅读 `story-writing/workflow.md`，写清主角诉求、阻力和场景变化。
2. 把自己的场景、`storyboard/workflow.md` 和 `prompts/storyboard-template.md` 交给你使用的 AI 助手。
3. 要求逐镜输出目的、观众视点、景别、机位、构图、运动和切镜理由。
4. 对照 `storyboard/checklist.md`，优先修改没有信息变化、空间不清或视点跳动的镜头。

方法文档可以跨助手使用；仓库中的 adapters 是使用说明，不是自动跨模型调度服务。
